# TrashTrack

TFM project focused on the design and development of an autonomous electronic node for smart waste container monitoring.

## Main features
- STM32WLE5 / Wio-E5
- LoRaWAN EU868
- SHT40 temperature and humidity sensor
- BMA400 accelerometer
- A02YYUW ultrasonic distance sensor
- External SPI Flash
- Custom 4-layer PCB

## Repository structure
- Hardware: schematics, PCB and manufacturing files
- Firmware: embedded software and drivers
- Documentation: complementary project documentation
